# فحم | FAHM Burger: ديمو مطعم

مشروع تجريبي (Concept Project) لعرض قدرات الشركة في بناء مواقع المطاعم والطلب الأونلاين.
المطعم وهمي بالكامل. الهوية موصوفة في [BRAND.md](BRAND.md).

## اللي فيه
**موقع العميل**
- منيو بالأقسام، وتبويبات بتتحرك مع السكرول
- اختيارات للمنتج: الحجم، والإضافات، و"خليها وجبة"، والملاحظات
- سلة جانبية فيها شريط "باقي كام على التوصيل المجاني"
- الطلب على واتساب برسالة جاهزة فيها تفاصيل الطلب
- صفحة إتمام الطلب: توصيل أو استلام، وطرق دفع محلية حسب السوق
- صفحة تتبع الطلب، وبتتحدث لحظياً لما الحالة تتغير من لوحة التحكم
- عربي وإنجليزي (RTL/LTR)، وسوقين: السعودية 🇸🇦 ومصر 🇪🇬
- مصمم للموبايل أولاً

**لوحة التحكم** (`/#/admin`)
- الإحصائيات: الطلبات، والمبيعات، ومتوسط الطلب، والمبيعات بالساعة، والأكثر مبيعاً
- إدارة الطلبات: فلترة، وتغيير الحالة، وإلغاء، وتنبيه لما يوصل طلب جديد
- إدارة المنيو: تعديل الأسعار، وإخفاء المنتجات اللي خلصت
- زرار لإرجاع بيانات الديمو الأصلية

## التشغيل
```
npm install
npm run dev
```

## الرفع (مجاناً)
```
npm run build
```
ارفع فولدر `dist` على Netlify (بالسحب والإفلات) أو Vercel أو GitHub Pages.
الموقع بيستخدم HashRouter، فمش محتاج أي إعدادات سيرفر.

## ملاحظات تقنية
- React 19 + Vite + Tailwind CSS 4
- البيانات محفوظة في `localStorage`، فالديمو مش محتاج سيرفر
- كل رسومات الأكل SVG مرسومة بالكود، فمفيش أي مشكلة حقوق في الصور
- الدفع **محاكاة بس**: مفيش أي خانات لبيانات البطاقة، ومفيش اتصال ببوابات دفع حقيقية
